# Vendor Management ERP

Vendor Management ERP for managing operations, workflows, records, billing, and reports.

## Overview

This repository is the APPNEURAL starter space for a vendor management product. It is intended to hold the product roadmap, data model, implementation notes, and future application source code for the ERP.

## Core Modules

- Vendor onboarding
- Contracts
- Performance
- Payments
